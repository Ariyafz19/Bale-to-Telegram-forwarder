# بله به تلگرام | Bale → Telegram Forwarder

فورواردر رایگان پیام‌های کانال عمومی **بلِه** (`ble.ir`) به **گروه تلگرام** و/یا **پیوی افراد**، روی
[Cloudflare Workers](https://workers.cloudflare.com) (پلن رایگان کافی است).

بدون نیاز به دسترسی ادمین یا API کانال بلِه: فقط صفحهٔ عمومی `https://ble.ir/s/<username>`
خوانده می‌شود و پیام‌های جدید شناسایی و ارسال می‌شوند.

## امکانات

-  فوروارد به **گروه تلگرام** و **پیوی اشخاص** (با آیدی عددی) — هر دو همزمان یا فقط یکی
-  هر کسی می‌تواند با `/start` دریافت پیام در پیوی را روشن کند؛ با `/unsubscribe` خاموش
-  پشتیبانی از **چند کانال** بلِه با برچسب فارسی
-  **پنل مدیریت دکمه‌ای** در تلگرام (`/panel`): فاصلهٔ بررسی، یادآور، ارسال پیوی، حذف کانال
-  یادآور صبح روزهای دانشگاه (شنبه/دوشنبه/چهارشنبه/پنجشنبه ساعت ۷:۰۰ تهران)
-  ارسال متن + عکس‌ها + لینک‌های پیام
-  endpoint های ادمین با کلید محافظت‌شده + `secret_token` برای وب‌هوک تلگرام
-  مصرف روزانه حدود ۱۵۰۰ درخواست از ۱۰۰٬۰۰۰ درخواستِ رایگانِ Cloudflare

## نحوهٔ کار

هر چند دقیقه (پیش‌فرض ۷، قابل تنظیم ۵–۱۰) یک کرون‌جاب صفحهٔ عمومی هر کانال را می‌خواند،
پیام‌ها را با هش مقایسه می‌کند (فهرست `seen` در KV) و فقط پیام‌های **جدید** را برای مقاصد
ثبت‌شده می‌فرستد. اولین اجرا فقط فهرست را می‌سازد و سیل نمی‌زند.

## پیش‌نیازها

1. اکانت رایگان [Cloudflare](https://dash.cloudflare.com)
2. یک ربات تلگرام (از [@BotFather](https://t.me/BotFather) بگیرید)
3. یک گروه تلگرامی که ربات **ادمین** آن باشد
4. کانال بلِه که **عمومی** باشد (صفحهٔ `ble.ir/s/<username>` بدون ورود قابل مشاهده)
5. Node.js 18+ روی سیستم

## نصب، گام به گام

```bash
git clone <repo-url> && cd <repo-folder>
npx wrangler login
```

۱) ساخت فضای KV و گذاشتن شناسه در `wrangler.toml`:

```bash
npx wrangler kv namespace create OFFSET_KV
# خروجی id را در wrangler.toml جایگزین YOUR_KV_NAMESPACE_ID کنید
```

۲) فایل متغیرهای محلی:

```bash
cp .dev.vars.example .dev.vars
# .dev.vars را با مقادیر واقعی پر کنید
```

| متغیر | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات از BotFather |
| `TELEGRAM_CHAT_ID` | آیدی عددی گروه مقصد (از @getidsbot یا @userinfobot در گروه) |
| `BALE_CHANNEL` | آیدی عمومی کانال بلِه (بدون @) |
| `BALE_LABEL` | برچسب فارسی برای شروع پیام |
| `ADMIN_KEY` | یک رشتهٔ تصادفی طولانی — کلید دسترسی endpoint های ادمین |

۳) ست کردن Secret ها روی ورکر (همان‌ها، چون `.dev.vars` فقط برای اجرای محلی است):

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID
npx wrangler secret put BALE_CHANNEL
npx wrangler secret put BALE_LABEL
npx wrangler secret put ADMIN_KEY
```

۴) استقرار:

```bash
npm install        # فقط برای نصب wrangler
npx wrangler deploy
# آدرس ورکر: https://<name>.<account>.workers.dev
```

۵) نصب وب‌هوک (فقط یک بار — secret وب‌هوک را خودش می‌سازد و منوی دستورات را ثبت می‌کند):

```
https://<worker-url>/setup-tg?key=<ADMIN_KEY>
```

۶) ربات را به گروه تلگرام اضافه و **ادمین** کنید، سپس در گروه:

```
/panel
```

## استفاده از پیوی (ارسال به اشخاص)

هر دو حالت (گروه + پیوی) همزمان فعال‌اند:

- **ثبت خود فرد:** کاربر در چت خصوصی ربات `/start` بزند؛ `/unsubscribe` برای لغو
- **ثبت توسط ادمین:** `/addpm 123456789 نام` (آیدی عددی را از @userinfobot بگیرید)
- حذف: `/delpm 123456789` یا دکمهٔ «مدیریت گیرندگان پیوی» در پنل
- روشن/خاموش کلیِ ارسال پیوی: دکمهٔ «👥 پیوی» در پنل

## دستورات ربات

| دستور | توضیح |
|---|---|
| `/panel` | پنل مدیریت (ادمین) |
| `/lastmessages N [channel]` | ارسال N پیام اخیر برای بازبینی (مثلاً `/lastmessages 4`) |
| `/status` | وضعیت: آخرین بررسی، کانال‌ها، یادآور |
| `/help` | راهنما |
| `/addchannel username برچسب` | افزودن کانال بلِه (ادمین) — از پنل هم می‌شود حذفش کرد |
| `/delchannel username` | حذف کانال (حداقل یکی باید بماند) |
| `/start` | عضویت دریافت پیوی (در چت خصوصی) |
| `/unsubscribe` | لغو عضویت پیوی |
| `/addpm` · `/delpm` · `/users` | مدیریت گیرندگان پیوی (ادمین) |

## endpoint های ادمین

همه با `?key=<ADMIN_KEY>` (یا هدر `x-admin-key`) محافظت می‌شوند:

| مسیر | کار |
|---|---|
| `GET /health` | سلامت ورکر (بدون کلید) |
| `GET /run` | بررسی فوری کانال‌ها |
| `GET /diag` | عیب‌یابی: اتصال تلگرام، وضعیت هر کانال، تعداد seen |
| `GET /setup-tg` | نصب وب‌هوک + secret + منوی دستورات (یک بار) |
| `GET /morning-test` | ارسال پیام آزمایشی یادآور صبح |
| `GET /test-tg` | پیام آزمایشی به گروه |
| `POST /tg-webhook` | وب‌هوک تلگرام (با secret خودکار) |

## کلیدهای KV

| کلید | محتوا |
|---|---|
| `cfg` | تنظیمات: کانال‌ها، فاصلهٔ بررسی، یادآور، فهرست پیوی |
| `seen:<channel>` | هش‌های پیام‌های دیده‌شده (حداکثر ۶۰) |
| `last_check` | آخرین زمان بررسی (میلی‌ثانیه) |
| `morning_sent:<date>` | جلوگیری از ارسال دوبارهٔ یادآور در یک روز |
| `wh_secret` | secret توکن وب‌هوک تلگرام |

## محدودیت‌ها و نکات

- کانال باید **عمومی** باشد؛ صفحهٔ خصوصی یا کپچا دار خوانده نمی‌شود
- هر اجرا حداکثر ۱۲ پیام جدید هر کانال را می‌فرستد (جلوگیری از flood)
- فاصلهٔ بررسی کمتر از ۵ دقیقه باعث مصرف زودترِ سهمیهٔ رایگان می‌شود
- اولین اجرا پیام‌های قبلی را ارسال **نمی‌کند**؛ برای دیدن تاریخچه از `/lastmessages` استفاده کنید
- بلِه گاهی ساختار صفحه را عوض می‌کند؛ اگر `/diag` خطای «پیامی پیدا نشد» داد، پارسر (`parseChannelPage` در `src/index.js`) باید به‌روز شود — اسکریپت `scripts/test-local.js` برای همین است

## تست محلی

بدون نیاز به توکن یا Cloudflare، پارسر را روی صفحهٔ زنده تست می‌کند:

```bash
node scripts/test-local.js your_bale_channel
```
